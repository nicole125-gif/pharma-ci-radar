# Bürkert、GEMÜ、Fujikin、ESG 精锐竞争战卡

更新日期：2026-06-08
适用场景：客户拜访、方案评审、竞争报价、输赢复盘
使用边界：战卡用于组织问题和证据，不代替数据表、证书、正式选型或真实报价。

## 1. Bürkert 自家产品战卡

### 我们卖的不是一只阀

**核心定位**

Bürkert 的主要差异不是每个单品都占优，而是能够把卫生阀、流量测量、气体质量流量控制、气动阀岛、工业通信和中国 Systemhaus 组合成完整控制回路。[BURKERT-COMPANY-001][BURKERT-CHINA-003]

**最强进入点**

| 客户任务 | 优先组合 | 价值证明 |
|---|---|---|
| WFI/PW分配与回水 | 2103/2104、多通阀体、8098 FLOWave、控制头/阀岛 | 减少接口；兼顾卫生隔离、测量、诊断和自动化 |
| 发酵供气 | 8741 MFC/MFM、压力与比例控制、阀岛 | 从单个MFC提升到多气体配比和控制回路 |
| 过滤与纯化 | 多通阀体、卫生阀、传感、8652阀岛 | 低死区流路、顺序控制、诊断和系统责任整合 |
| CIP/SIP | 卫生隔膜阀、过程阀、流量测量、阀岛 | 主工艺和辅助回路统一设计但分级选型 |
| 撬装/OEM设备 | 产品组合、控制柜、Systemhaus | 降低多供应商接口和调试工作量 |

**五个必须主动证明的问题**

1. 本项目中完整控制回路究竟减少了哪些接口、调试和维护工作？
2. 报价型号在中国的产地、库存、交期和服务责任是什么？
3. 卫生阀具体配置的材质、Ra、膜片、连接和证书是什么？
4. 8098、8741、8652等产品是否满足该工况和控制架构，而不只是产品族存在？
5. 总拥有成本优势能否用项目数据证明？

**不能说**

- “产品线更全，所以每个项目都更优。”
- “本地有工厂，所以所有型号交期都短。”
- “完整系统一定比单品采购便宜。”

## 2. 对 GEMÜ 战卡

### 竞争画像

**对方最可能强调**

- 无菌隔膜阀专业度和 BioStar 产品线。
- P600M/P600S 多通阀块的紧凑、低死区和定制能力。
- SUMONDO 一次性方案。
- 膜片追溯、CONEXO 和制药阀门文件化。
- 中国研发、生产、销售和服务组织。[GEMU-650-001][GEMU-MULTIPORT-001][GEMU-SINGLEUSE-001][GEMU-CHINA-001]

**当前目录口径**

- 截至 2026-06-09，官网目录化结果为 159 个当前产品系列和 5 个精选解决方案记录。[GEMU-SERIES-650][GEMU-SERIES-P600M-P600S-P500M]
- 反馈与控制产品优先按 1232、1234、1236、1240、1241、1242、1434、1435、1436、1441 核对；不要把历史 1235 默认视为当前系列。
- 本轮当前英文 sitemap 未发现旧资料中的 3030、3021；流量产品应按当前目录重新锁定具体系列。
- 官网明确标注制药行业只能证明行业定位，不能替代具体配置的无菌适用性、认证和验证文件。

**最危险的项目**

- 客户只采购卫生隔膜阀或复杂多通阀块。
- 既有装机和验证文件偏向 GEMÜ。
- 一次性工艺、快速换批和交叉污染控制是核心诉求。
- 客户把“阀门专业品牌”作为首要筛选条件。

**不要硬碰的方式**

- 不要泛称 Bürkert 隔膜阀“全面更好”。
- 不要在没有流路图时只按阀位数量和单阀价格报价。
- 不要否认 GEMÜ 的无菌阀和多通阀块证据。

### Bürkert 应对路径

1. **先承认对手强项。** GEMÜ 在无菌隔膜阀和多通阀块上是强竞争者。
2. **再判断采购任务。** 客户买的是一只阀、一个阀块，还是包含测量、MFC、阀岛和控制的设备功能？
3. **扩大可比范围。** 把接口数量、传感、诊断、通信、调试、备件和责任边界纳入比较。
4. **锁定中国交付事实。** 询问具体产品产地、工程地点、膜片和备件库存，不从“中国有工厂”直接推断。
5. **用项目条件证明。** 对多通阀块取得 P&ID、阀位矩阵、排空和死区要求后再形成方案。

### 客户发现问题

- 选择 GEMÜ 的核心原因是产品参数、既有验证、品牌指定还是安装基础？
- 项目是否还包含流量测量、气体控制、阀岛和控制柜？
- 多通阀块由谁负责流路优化、排空验证和后续变更？
- 一次性方案的灭菌、供应连续性和废弃成本如何评价？
- 中国供货产品的实际产地和承诺交期是什么？

### 赢单信号

- 客户希望减少供应商和控制接口。
- 项目同时涉及 MFC、FLOWave、阀岛或控制柜。
- OEM希望复制标准模块并缩短后续设备调试。
- 客户愿意按生命周期成本而非单阀价格评价。

### 输单风险

- 规格书锁定 GEMÜ 型号或既有验证。
- 项目价值几乎全部集中在复杂阀块本体。
- 我方无法及时提供同等级卫生文件或工程图。
- 我方仍以产品目录作答，没有给出完整流路方案。

## 3. 对 Fujikin 战卡

### 竞争画像

**对方最可能强调**

- 高纯流体控制、阀件和接头经验。
- BNW 卫生隔膜阀。
- FCS Thermal 质量流量控制器。
- MINUCON 微小流量调节能力。
- 中国多地办公室、服务中心和制造实体。[FUJIKIN-BNW-001][FUJIKIN-FCS-001][FUJIKIN-MINUCON-001][FUJIKIN-CHINA-001]

**最危险的项目**

- 高纯气体、精密供气和卫生阀同时出现。
- 客户或设备商已有 Fujikin 半导体/高纯供应关系。
- 项目关注单个精密流量或微流量控制部件。
- 采购将集团高纯经验直接作为制药适用性的替代证明。

**最大判断陷阱**

不能把 Fujikin 的全部半导体、高纯气体能力直接写成中国制药项目能力；也不能因此否定其具体卫生阀和 MFC 产品。

### Bürkert 应对路径

1. 锁定对手完整型号和所属产品线。
2. 对 BNW 按口径、Cv、阀体、膜片、Ra、连接、认证和产地逐项比较。
3. 对 FCS Thermal 按气体、标况、流量、压力、精度、响应和校准条件归一化。
4. 要求提供同类制药应用、中国服务和校准证据。
5. 把单个 MFC 比较扩展到配气、压力控制、阀岛、通信和调试责任。

### 客户发现问题

- 报价产品属于制药卫生、高纯半导体还是通用工业系列？
- 制药项目要求的证书是否对应本次具体订货型号？
- 中国校准、维修、备机和现场支持如何安排？
- 客户选择 Fujikin 是技术、价格、既有关系还是指定品牌？
- 高纯经验在本项目中具体降低了什么风险？

### 赢单信号

- 客户需要完整发酵供气回路而非单个 MFC。
- 项目重视跨产品通信、诊断和标准化复制。
- 对手不能提供明确的制药型号、文件或中国服务边界。

### 输单风险

- 客户既有高纯供应链强绑定 Fujikin。
- 项目只比较单个高精度部件，我方系统优势无法变现。
- 我方没有同条件校准、响应和总成本数据。

## 4. 对 ESG 精锐战卡

### 竞争画像

**对方最可能强调**

- 青岛本地制造、阀体加工和装配能力。
- A00 卫生隔膜阀、100 角座阀、801 疏水阀等较完整阀门包。
- 制药设备、纯化水、发酵、CIP/SIP 等应用覆盖主张。
- 潜在成本、响应和定制便利。[ESG-CHINA-001][ESG-PHARMA-001][ESG-100-001][ESG-801-001]

**最危险的项目**

- 标准卫生阀、公用工程阀和设备商批量采购。
- 客户优先考虑国产替代、采购成本和响应速度。
- 项目对数字化、传感、MFC和完整控制回路要求较低。
- 客户愿意自行承担更多验证和集成工作。

**最大判断陷阱**

不能因其是本土厂商就预设更便宜、更快，也不能因公开证据较弱就预设产品不合格。

### Bürkert 应对路径

1. 把网页参数转换为文件审查：数据表、证书原件、适用型号和有效期。
2. 比较范围包含 Ra 检测、材料证明、膜片批次、变更控制、备件和现场服务。
3. 区分低风险标准阀与关键无菌主工艺阀，采用不同资格审查强度。
4. 对设备包强调传感、阀岛、通信、调试和生命周期支持。
5. 用真实报价和实际交期验证本地优势，不用品牌判断替代数据。

### 客户发现问题

- ESG 的优势来自价格、标准库存、自产阀体还是快速定制？
- 当前证书和数据表是否覆盖报价的具体型号？
- 膜片、密封和关键原料的供应商及变更控制如何管理？
- 全国现场服务、备件和故障响应由谁承担？
- 客户愿意为验证文件、诊断和降低停机风险支付多少？

### 赢单信号

- 项目为关键无菌工艺，客户重视审计、追溯和变更控制。
- 项目需要传感、MFC、阀岛和系统联调。
- ESG不能提供当前证书、批次文件或可核验案例。

### 输单风险

- 项目是标准阀批量采购且主要按初始价格决策。
- 我方无法量化文件、可靠性和服务的商业价值。
- 我方报价响应、标准品交期或备件供应明显偏弱。

## 5. 三分钟临场检查

进入任何竞争会议前，必须能回答：

1. 客户买的是产品、功能模块还是完整控制回路？
2. 对手具体公司、系列、型号和配置是什么？
3. 当前哪些参数真正可比，哪些仍不可比？
4. 客户前三项决策标准是什么？
5. 我方优势能否转成该项目的可量化价值？
6. 对手最强证据是什么？
7. 我方最薄弱的证据是什么？
8. 需要客户、应用工程或供应链补充哪三项信息？
9. 报价是否包含同等文件、服务和贸易条款？
10. 本次会议的唯一下一步承诺是什么？

## 6. 战卡更新规则

- 公开产品事实进入证据表后才能更新“产品能力”。
- 一个销售项目只能作为单一案例，不能直接升级为市场普遍结论。
- 价格和交期至少积累三个可比项目，才可形成方向性判断。
- 涉及安全、合规和关键无菌工艺的结论，必须有数据表或证书原件。
- 每季度检查产品停产、新品、组织变化和失效链接。
