## 1. 使用原则

这份手册用于选型准备、客户访谈、竞争项目复盘和内部培训，不替代产品数据表、证书原件或正式技术确认。

每次比较必须区分四个层级：

1. **产品族**：说明公司是否覆盖某类能力。
2. **系列**：说明典型技术路线和目标场景。
3. **具体型号/配置**：用于参数、认证和价格比较。
4. **项目证据**：用于判断中国交付、客户接受度和商业竞争力。

禁止用某个代表型号推断全系列，也禁止把全球在售产品直接写成中国现货产品。

## 4. 制药应用作战地图

### 4.1 WFI/PW制药用水

**客户核心需求**

- 卫生设计、全排空、低死区和可验证材料。
- 稳定流量测量、温度监控和回水控制。
- CIP/SIP耐受、材料批次和校准文件。

**Bürkert组合**

- 2103/2104及多通阀体负责隔离和分配。
- FLOWave负责卫生流量测量。
- 控制头、阀岛和Systemhaus完成自动化集成。

**主要对手**

- GEMÜ：隔膜阀和多通阀块专业度强。
- Fujikin：BNW具备卫生阀参数基础。
- ESG：A00可进入标准阀和设备配套项目。

**关键提问**

1. 该项目真正决定采购的是单阀价格，还是排空、焊点数量、验证文件和调试时间？
2. 回路中需要测量、控制和诊断到什么程度？
3. 对手报价是否包含同等Ra、膜片、材料证明、执行反馈和中国服务？

### 4.2 发酵与生物反应供气

**客户核心需求**

- 空气、氧气、氮气和二氧化碳的准确配比。
- 快速响应、宽量程和稳定重复性。
- 与压力、阀门、PLC及批次控制集成。

**Bürkert组合**

- 8741 MFC/MFM负责气体计量与控制。
- 比例阀、压力控制和阀岛形成气路执行层。
- 卫生阀和传感器覆盖反应器液路及辅助回路。

**主要对手**

- Fujikin FCS Thermal是最直接的MFC产品重叠。
- GEMÜ更可能从阀门和过程控制侧参与。
- ESG公开资料未证明自有MFC和传感产品族。

**关键提问**

1. 比较是否基于相同气体、标况、流量范围、入口压力和精度定义？
2. 校准、换气体、维护和中国服务如何执行？
3. 客户需要单个MFC，还是完整配气歧管、阀岛和控制逻辑？

### 4.3 CIP/SIP与蒸汽公用工程

**客户核心需求**

- 耐温耐压、循环寿命、冷凝水排放和可靠隔离。
- 主工艺与辅助回路清晰分级。
- 易维护、备件稳定和停机时间可控。

**竞争结构**

- Bürkert、GEMÜ可同时覆盖卫生主工艺阀和辅助过程阀。
- ESG 100角座阀和801疏水阀形成设备阀门包竞争。
- Fujikin具备多类工业阀，但须确认制药公用工程具体系列。

**关键提问**

1. 介质是纯蒸汽、工业蒸汽、冷凝水还是清洗液？
2. 阀门失效位、频次、压差和水锤风险是什么？
3. 竞争报价是否把主工艺卫生要求错误套用到辅助回路，或反过来降低关键阀要求？

### 4.4 过滤、纯化与色谱

**客户核心需求**

- 低死区流路、紧凑阀块、顺序控制和完整性测试。
- 减少连接点、焊点和滞留体积。
- 快速换批、可靠排空和可追溯维护。

**竞争结构**

- GEMÜ P600系列在多通阀块和一次性方案上是最强直接威胁。
- Bürkert应以多通阀体、传感、阀岛和控制回路整体回应。
- Fujikin与ESG公开的复杂阀块证据不足，不能据此判定其没有项目定制能力。

**关键提问**

1. 能否拿到P&ID和阀位矩阵，而不是按单阀清单报价？
2. 哪些连接可通过阀块减少，节省多少空间、焊接和验证工作？
3. 排空性、死区和PUPSIT功能由谁负责验证？

### 4.5 灌装、定量与无菌输送

**客户核心需求**

- 重复性、低泄漏、低剪切、快速切换和易清洗。
- 紧凑安装、执行反馈和设备节拍匹配。

**竞争结构**

- Bürkert可组合微流体、阀门、传感和控制。
- GEMÜ有灌装阀、隔膜阀和一次性能力。
- Fujikin MINUCON代表精密微流量调节能力。
- ESG公开产品族包含灌装阀和角座阀，但需逐型号确认卫生边界。

**关键提问**

1. 控制目标是质量、体积、时间还是液位？
2. 可接受的重复性、滴漏、残留和换液时间是多少？
3. 对手展示的是阀的最小Cv，还是完整系统在实际介质下的定量表现？

### 4.6 无菌取样与一次性工艺

**客户核心需求**

- 降低污染风险、减少清洗验证和缩短换批。
- 接液材料、灭菌方式、完整性和供应连续性可证明。

**竞争结构**

- GEMÜ SUMONDO的一次性证据最明确。
- ESG曾公开A31无菌取样阀，但当前产品和文件需重新确认。
- Bürkert需要明确自有产品、合作产品和系统集成边界。

**关键提问**

1. 客户选择一次性的经济驱动是什么：产能、换批、清洗、验证还是交叉污染风险？
2. 单次使用组件的灭菌、运输、连接和废弃责任如何分配？
3. 供应中断时是否有第二来源和可接受的变更控制？

## 5. 参数可比性检查表

卫生阀进入横向比较前，至少锁定以下字段：

| 分组 | 必填字段 |
|---|---|
| 工况 | 介质、温度、压力、压差、流向、频次、清洗和灭菌条件 |
| 阀体 | DN、结构、材质牌号、制造方式、连接、Ra、排空和死区 |
| 膜片/密封 | 材料、复合结构、温压范围、寿命依据、批次追溯和变更控制 |
| 执行 | 气动/电动、失效位、气源、开关时间、反馈、调节能力和防护 |
| 自动化 | 信号、协议、诊断、阀岛兼容、资产管理和网络架构 |
| 合规 | FDA、USP、3-A、EHEDG、ASME BPE、EC 1935/2004及证书适用范围 |
| 商业 | 产地、库存、交期、价格条款、保修、备件、服务和文件交付 |

任一关键字段不同，就先标记“不可直接比”，再决定是否做条件归一化。

## 6. 竞争项目问法

### 对GEMÜ

- 客户选择GEMÜ是因为650单阀、P600阀块、SUMONDO，还是既有验证和安装基础？
- 中国报价产品的实际产地、膜片供货和多通阀块工程地点是什么？
- 若项目同时需要流量测量、MFC、阀岛和诊断，接口和责任边界由谁承担？

### 对Fujikin

- 竞品型号属于制药卫生、高纯半导体还是通用工业系列？
- BNW具体配置是否真正满足项目的Ra、膜片、连接和证书要求？
- FCS Thermal是否有同类制药气体、同量程和中国服务案例？

### 对ESG精锐

- 能否提供当前数据表和证书原件，而不是网页参数或宣传摘要？
- 同规格报价是否包含材料证明、Ra、膜片追溯、执行反馈和验证文件？
- 本地交付优势是标准品库存、自产阀体、快速定制，还是销售承诺？对应数据是什么？

## 7. 不过度承诺的竞争话术

| 场景 | 建议表达 | 避免表达 |
|---|---|---|
| 对GEMÜ | “GEMÜ在隔膜阀和多通阀块上证据很强；本项目还应比较测量、气动控制、诊断和系统责任边界。” | “我们的隔膜阀一定全面更好。” |
| 对Fujikin | “其高纯和MFC能力值得重视，但应按具体制药型号、认证和中国交付逐项确认。” | “半导体产品不能用于制药。” |
| 对ESG | “本土制造可能带来成本和响应机会；关键无菌工艺仍需用证书、追溯和项目数据验证。” | “国产品牌质量一定不行。” |
| 价格 | “目前缺少同规格、同条款数据，建议建立净价和总拥有成本对比。” | “对手肯定更便宜/更贵。” |
| 交期 | “请区分标准库存、常规生产和定制阀块交期，并核对历史准时交付。” | “本地生产一定更快。” |

## 9. 30/60/90天熟悉路径

### 0至30天：建立产品骨架

- 能不看资料讲清四家公司定位、一级产品线和三至五个代表系列。
- 完成卫生隔膜阀参数可比性练习，不混淆系列与具体配置。
- 跟随一个WFI项目和一个发酵供气项目走完选型逻辑。

**验收：** 用15分钟讲清四家公司差异，并能指出至少五个“当前无法判断”的边界。

### 31至60天：建立应用判断

- 按WFI、发酵、CIP/SIP、过滤纯化、灌装和一次性工艺完成场景演练。
- 获取三家公司各至少两个真实竞争报价或输赢项目。
- 与应用工程、售后和销售分别完成一次访谈。
