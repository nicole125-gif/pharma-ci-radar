# Bürkert 与 GEMÜ 制药卫生阀自动化深度学习课

## 课程目标

本课用于训练产品经理、销售和应用工程在制药客户场景中识别 Bürkert 与 GEMÜ 的直接对标点，重点覆盖卫生级隔膜阀、多通阀块、控制头、定位器和阀岛。

完成后应能做到：

- 说清客户为什么问卫生隔膜阀，而不是只背型号。
- 区分二位二通、T 型、罐底、多通阀块和一次性流路的客户任务。
- 将 Bürkert Type 2030/2031/2032/2033/2034/2035/2036/2103/2104/2105 与 GEMÜ 650/649/P600M-P600S-P500M/1436/1441/1236 放在正确对标框架里。
- 遇到参数不完整时主动列出必问工况，而不是外推品牌优劣。
- 把公开证据、企业宣传和内部待验证问题分开表达。

## 证据边界

本课只使用公开研究库中的证据和产品目录，不等同于应用工程批准、验证文件或项目报价。

可直接引用的证据包括：

- `BURKERT-DIAPHRAGM-001`：Type 2103 卫生隔膜阀公开资料含 316L 阀体、Ra 和膜片配置。
- `BURKERT-DIAPHRAGM-002`：Type 2104 T 型隔膜阀公开资料含压力、温度和卫生材料声明下载。
- `BURKERT-2103-001`：Type 2103 官方页面将其用于卫生和无菌要求较高的介质控制。
- `BURKERT-AUTOMATION-001`：Bürkert 隔膜阀自动化覆盖中央、分散和分布式方案。
- `BURKERT-8652-001`：Type 8652 AirLINE 阀岛用于过程自动化并提供诊断和通信能力。
- `GEMU-650-001`：GEMÜ 650 BioStar 是无菌应用气动隔膜阀，公开页面列出 CIP/SIP 能力。
- `GEMU-649-001`：GEMÜ 649 eSyDrive 是电动隔膜阀系列。
- `GEMU-1441-001`：GEMÜ 1441 cPos-X 是智能数字电气定位器。
- `GEMU-MULTIPORT-001`：GEMÜ P600M 多通阀块覆盖复杂无菌流路并列出多项符合性。

仍需内部验证的问题：

- 中国项目净价、折扣、库存、产地和交期。
- 特定客户装机量、复购率和售后表现。
- 具体阀体、膜片、连接、表面粗糙度和批次文件是否满足客户 URS。
- 电动阀与气动阀在目标工况下的速度、故障安全位、诊断和验证成本。

## Bürkert 学习重点

### 1. 卫生阀不是单个 Type，而是一组流路选择

学习顺序：

1. 2030/2031：气动二位二通卫生隔膜阀，适合建立隔膜阀基本框架。
2. 2032/2104：T 型隔膜阀，用于分支、切换和低残留设计。
3. 2033/2105：罐底隔膜阀，用于配液罐、生物反应器或储罐排放。
4. 2034/2035/2036：多功能块和 Robolux，多用于复杂低死区流路。
5. 2103：ELEMENT 不锈钢执行器平台，是制药主工艺对标时最常被拿来讲的代表 Type。

关键记忆：

- 2030/2031 解决“关断和隔离”。
- 2032/2104 解决“分支和 T 型流路”。
- 2033/2105 解决“罐底排空”。
- 2034/2035/2036 解决“多阀位、低死区、少焊点、复杂流路”。
- 2103 解决“卫生隔膜阀加分散自动化平台”的叙事。

### 2. 自动化要分三层

| 层级 | Bürkert 重点 | 客户关心点 |
|---|---|---|
| 阀顶反馈和开关控制 | 8690/8691/8695/8697 | 阀位反馈、现场可视、接线、卫生环境适配、维护便利性。 |
| 调节和定位 | 8692/8693 等定位控制产品 | 控制精度、响应速度、诊断、气源、信号和通信。 |
| 阀岛与系统通信 | 8652 AirLINE | 柜内集中控制、诊断显示、PROFINET 等通信、维护和模块化扩展。 |

销售表达时不要只说“我们也有控制头”。更好的表达是：

> 这条线是要单阀状态反馈、阀顶分散自动化，还是集中阀岛加诊断？三种架构的接线、维护和验证责任不同，需要先和自动化团队对齐。

## GEMÜ 学习重点

### 1. GEMÜ 650 是卫生隔膜阀正面对标核心

GEMÜ 650 BioStar 是无菌应用中最需要优先掌握的系列。对标时不要泛泛比较“隔膜阀谁好”，而要拆成：

- 阀体构型和流路。
- 316L 牌号、Ra、连接和膜片材料。
- CIP/SIP 和蒸汽灭菌条件。
- 气动执行方式、故障安全位和反馈选项。
- 材料声明、证书、批次文件和验证包。

### 2. GEMÜ 649 代表电动隔膜阀竞争

GEMÜ 649 eSyDrive 的核心不是“电动”两个字，而是客户是否需要：

- 无压缩空气架构。
- 电动执行器的参数化和诊断。
- 开关或调节能力。
- 更少气动附件和更高设备一体化。

Bürkert 不能简单用气动 Type 2103 对比 649。应转到电动隔膜阀平台，按断电策略、推力、速度、控制模式、通信和卫生阀体组合比较。

### 3. P600M/P600S/P500M 是系统工程竞争

P600 系列多通阀块不是普通三通阀的替代品。它竞争的是：

- P&ID 简化。
- 死区和排空。
- 焊点数量。
- 阀位矩阵。
- 传感器集成。
- 验证文件和系统责任边界。

遇到 P600 类项目时，必须先画流路和阀位矩阵，再谈 Type 或系列。

## 对标决策路径

1. 确认客户任务：隔离、切换、排空、调节、分配、PUPSIT、一次性、诊断。
2. 确认过程阶段：发酵、配液、纯化、过滤、CIP/SIP、公用工程、灌装。
3. 确认工况：介质、DN、压力、温度、灭菌、循环频率、安装方向。
4. 确认卫生要求：Ra、死区、排空、材料、膜片、连接、证书和批次文件。
5. 确认自动化架构：手动、气动开关、定位调节、电动、阀岛、现场总线。
6. 确认证据等级：官方产品页、技术数据表、证书、案例、内部验证。
7. 输出候选：给出 Bürkert 候选 Type、GEMÜ 对标系列、不可比较项和待验证问题。

## 常见误区

| 误区 | 正确做法 |
|---|---|
| 用品牌评价替代型号和配置比较。 | 回到具体 Type、系列、阀体、膜片、连接和工况。 |
| 把全球产品能力写成中国现货或交期。 | 只写公开可见性，价格、库存和交期进入内部验证。 |
| 用二位二通隔膜阀替代多通阀块。 | 多通阀块必须按 P&ID、阀位、死区、排空和焊点比较。 |
| 用气动阀直接对比电动阀。 | 先确认客户是否要无气源、电动诊断、断电策略和通信。 |
| 把企业宣传当独立验证。 | CLAIM 保留为宣传性证据，正式结论需 A/B 级或内部验证。 |

## 课堂演练

### 演练 1：主工艺卫生隔膜阀

客户说：“我们在配液 skid 上看了 GEMÜ 650，想知道 Bürkert 是否能替代。”

必须追问：

1. 介质、批次风险和清洁策略是什么？
2. DN、压力、温度、CIP/SIP 最高条件是什么？
3. 阀体是二位二通、T 型、罐底还是阀块？
4. 接液材料、Ra、膜片、连接和证书要求是什么？
5. 是否需要阀顶反馈、定位调节或现场总线？
6. 是否已有客户 URS、P&ID、阀位表和验证文件清单？

合格回答：

> 可以对标，但要先限定在相同阀体任务和配置下。若是二位二通气动卫生隔膜阀，可先看 Bürkert 2103/2030 与 GEMÜ 650；若涉及 T 型、罐底或低死区阀块，需要切换到 2104/2105/2034/2035/2036 与 GEMÜ 相应系列或 P600 阀块比较。

### 演练 2：电动隔膜阀

客户说：“我们想用 GEMÜ 649，原因是设备不想接气源。”

必须追问：

1. 是完全无气源，还是局部减少气动附件？
2. 阀门是开关还是调节？
3. 需要什么断电安全位？
4. 执行速度、推力、循环频率和温度条件是什么？
5. 通信、诊断和参数化要求是什么？
6. 卫生阀体和材料文件要求是否与气动阀相同？

合格回答：

> 这不是 2103 与 649 的直接单品比较，而是气动自动化架构与电动隔膜阀架构比较。Bürkert 需要拿电动隔膜阀平台和控制架构回应，并把断电策略、控制模式、诊断、通信和验证文件列为关键比较项。

### 演练 3：P600 多通阀块

客户说：“GEMÜ 提供 P600 多通阀块，你们用几个三通阀能不能替？”

必须追问：

1. P&ID 和阀位矩阵是什么？
2. 每个阀位的排空方向和死区要求是什么？
3. 焊点、取样点、传感器和排放路径如何布置？
4. 谁负责阀块设计、制造、文件和验证？
5. 是否涉及 PUPSIT、过滤器完整性测试或复杂旁路？

合格回答：

> 不能先承诺“几个三通阀可替代”。多通阀块竞争的是死区、排空、焊点、集成和验证责任。应先把流路画清楚，再判断 Bürkert 2034/2035/2036/8806 或系统方案是否更适合。

## 自测题

1. 为什么 GEMÜ 650 与 Bürkert 2103 可以成为直接对标，但仍不能品牌级比较优劣？
2. 客户要求“无气源”时，为什么不能用 Bürkert 气动隔膜阀直接回应 GEMÜ 649？
3. 多通阀块项目中，P&ID、阀位矩阵、死区、排空和焊点分别影响什么？
4. Type 8652 与 8691/8697 的客户任务有什么区别？
5. 哪些信息属于公开证据，哪些必须进入内部验证？

## 通过标准

学习者完成本课后，应提交一页对标表，至少包含：

- 3 个 Bürkert 候选 Type。
- 3 个 GEMÜ 对标系列。
- 5 个必问工况。
- 3 个不可直接比较边界。
- 5 个证据编号。
- 2 个内部验证问题。

教练复核重点：

- 是否把 Type、系列、阀体任务和自动化架构讲清楚。
- 是否避免把全球公开产品写成中国库存、交期或价格事实。
- 是否能在参数不足时输出“无法判断”和下一步验证动作。
