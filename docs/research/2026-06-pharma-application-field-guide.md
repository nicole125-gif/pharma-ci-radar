# 制药应用选型与竞争问诊指南

更新日期：2026-06-09
配套数据：`2026-06-pharma-application-selection-matrix.csv`

## 1. 使用方式

收到客户需求后，不先从品牌或Type开始，而按以下顺序判断：

1. **客户任务**：隔离、调节、测量、定量、分配、取样、完整性测试还是自动化。
2. **过程风险**：无菌主工艺、卫生非无菌、洁净公用工程、普通公用工程或设备内部气路。
3. **工况边界**：介质、流量、压力、温度、压差、口径、连接、材料和清洗灭菌。
4. **控制边界**：开关、调节、测量、反馈、阀岛、PLC通信、诊断和维护责任。
5. **文件边界**：材料证明、Ra、膜片、认证、校准、批次、变更和验证文件。
6. **商业边界**：数量、净价、贸易条款、产地、承诺交期、实际交期、备件和服务。

任何一层未锁定，都不应把候选产品变成确定选型或形成价格优劣结论。

## 2. 五步选型路径

### 第一步：判断过程等级

| 过程等级 | 典型位置 | 选型重点 |
|---|---|---|
| 无菌主工艺 | 配液、纯化、反应器、无菌输送 | 排空、死区、Ra、膜片、连接、CIP/SIP和验证 |
| 卫生非无菌 | 部分食品级或清洁设备流路 | 易清洗、材料、连接和维护 |
| 洁净公用工程 | 洁净蒸汽、工艺气体、PW/WFI辅助回路 | 介质纯度、温压、泄漏、排水和文件 |
| 普通公用工程 | 工业蒸汽、冷却水、压缩空气 | 可靠性、寿命、容量、维护和成本 |
| 仪器/设备内部 | 微量定量、分析、气路 | 死体积、响应、重复性、尺寸和控制接口 |

### 第二步：确定决策单元

- **单阀**：客户只采购一个明确阀位，系统广度未必创造价值。
- **阀门包**：多个标准阀位，规格分级和总价/交期成为关键。
- **功能模块**：阀块、MFC歧管、PUPSIT、定量或取样，需要完整功能验证。
- **完整回路**：阀门、测量、控制、通信和调试责任应一起比较。

不要用完整回路优势回答纯单品采购，也不要用单阀价格评价复杂功能模块。

### 第三步：建立候选与排除项

候选产品只表示“值得进一步选型”，不表示已经适用。

立即排除或暂停的典型情况：

- 隔膜阀只有DN和316L，没有阀体结构、Ra、膜片、连接和工况。
- MFC没有气体、标况、量程、入口压力和精度定义。
- 多通阀块没有P&ID、阀位矩阵、排空方向和死区要求。
- 灌装只有最小Cv，没有目标体积、节拍、重复性和实际介质。
- 一次性方案没有接液材料、辐照、完整性和供应连续性。
- 认证只有网页图标或宣传文字，没有文件原件和适用型号。
- 中国有工厂，但无法证明报价型号的产地、库存和交期。

### 第四步：识别真正的竞争单位

| 客户任务 | 主要竞争单位 | 常见误判 |
|---|---|---|
| 卫生隔离 | 具体阀体和膜片配置 | 用品牌或代表型号覆盖全系列 |
| 复杂分配 | 完整流路与阀块工程 | 按单阀数量和单价比较 |
| 发酵供气 | 多气体控制回路 | 只比较一个MFC的精度数字 |
| CIP/SIP | 分级阀门和测量组合 | 所有阀位使用同一卫生等级 |
| 精密灌装 | 实际介质下的定量功能 | 把最小Cv当作定量精度 |
| 自动化 | I/O、协议、诊断和维护体系 | 只比较是否有定位器 |
| 本土替代 | 同等规格的总商业条件 | 由品牌国别推断价格和交期 |

### 第五步：形成下一步承诺

每次客户或内部评审结束，必须形成一种可验证的下一步：

- 客户提供P&ID、阀位矩阵或完整工况。
- 应用工程输出候选Type和排除理由。
- 供应链确认产地、库存和承诺交期。
- 质量团队核验证书、材料和批次文件。
- 销售补齐同规格报价和客户决策标准。
- 售后提供故障、备件或响应记录。

“继续沟通”不是有效下一步。

## 3. 四家公司场景记忆

### Bürkert

- 强项不是每个单品都绝对领先，而是把阀门、测量、MFC、比例控制、阀岛、通信和Systemhaus组成完整控制回路。
- 单阀、纯阀块或极度价格敏感项目中，系统广度可能无法转化为采购价值。
- 关键动作是先识别决策单元，再决定是否扩大比较范围。

### GEMÜ

- 在卫生隔膜阀、多通阀块、一次性和PUPSIT场景最危险。
- P600/P500应按流路工程比较，SUMONDO应按一次性接液和供应体系比较。
- 不要否认其专业优势；应判断项目是否还包含测量、MFC、阀岛和完整系统责任。

### Fujikin

- 生命科学卫生阀、跨行业精密流控和半导体高纯能力必须分开。
- BNW/BSW/LPS可直接进入卫生阀比较；FCS Thermal可进入MFC比较。
- FINE PURE、IGS和FCS Pressure证明高纯深度，但不能自动替代制药型号、文件和中国案例。

### ESG精锐

- A00/A01和100系列是最可信的标准阀直接重叠。
- A31、灌装阀、调节阀和0P1扩展了设备阀门包，但证据成熟度较低。
- 认证、价格和交期必须用原件与真实项目验证；不能因本土品牌预设优劣。

## 4. 会议前一分钟检查

1. 客户任务和过程等级是什么？
2. 竞争单位是单阀、阀门包、功能模块还是完整回路？
3. 当前还缺哪三个决定性工况？
4. 哪个竞品系列真正可比？
5. 哪个参数或宣传最容易造成错误比较？
6. 我方候选Type的排除条件是什么？
7. 本次必须取得哪一份证据或工程输入？
