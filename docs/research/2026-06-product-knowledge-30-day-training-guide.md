# 四家公司产品知识30天训练指南

更新日期：2026-06-11

适用对象：战略、产品经理、应用工程、行业销售及销售赋能人员。

配套文件：

- `2026-06-product-knowledge-30-day-curriculum.csv`
- `2026-06-product-knowledge-training-progress.csv`
- `2026-06-product-knowledge-training-scorecard.csv`
- `2026-06-product-knowledge-assessment.md`

## 1. 训练目标

30天后，学员应能独立完成四件事：

1. 讲清 Bürkert、GEMÜ、Fujikin、ESG 精锐的产品骨架和能力边界。
2. 在比较前识别型号、配置、工况和证据是否可比。
3. 从客户任务形成候选产品、排除条件和下一步工程输入。
4. 把竞争判断转成有证据的销售动作、产品动作和内部验证任务。

这不是背型号比赛。训练重点是“知道如何定位、如何排除、如何查证、如何行动”。

## 2. 课程结构

| 阶段 | 天数 | 核心能力 | 阶段输出 |
|---|---:|---|---|
| 产品骨架 | 1至7 | 四家公司定位、重点系列和边界 | 公司记忆地图与代表产品卡 |
| 参数与证据 | 8至10 | 可比字段、证书审查和第一阶段检查 | 卫生阀比较表与DAY-10成绩 |
| 应用选型 | 11至20 | WFI、发酵、阀块、CIP、一次性等场景 | 场景工作纸与DAY-20成绩 |
| 竞争行动 | 21至29 | 三家竞品攻防、项目事实和组织行动 | 战卡、项目复盘与综合案例 |
| 结业评估 | 30 | 闭卷知识、场景答辩和目录检索 | DAY-30成绩与60天行动 |

课程主表是唯一日程来源。教练可以调整日期，但不得删除必交产出或降低阶段门槛。

## 3. 每日执行

建议每天投入60至90分钟：

1. **学习20分钟**：阅读课程主表指定材料，只读与当日目标相关的章节。
2. **检索15分钟**：在CSV或手册中定位具体Type、系列或证据。
3. **练习30分钟**：完成当日场景、比较或问诊任务。
4. **复盘10分钟**：记录一个已确认事实、一个边界和一个待验证问题。
5. **教练复核**：检查产出是否可追溯、是否越过证据范围。

学员在 `training-progress.csv` 中每天一行。只有以下条件同时满足，状态才能写为 `COMPLETE`：

- 已填写产出位置。
- 已由教练复核。
- `coach_result=PASS`。
- 已记录完成日期。

## 4. 角色分工

| 角色 | 责任 |
|---|---|
| 项目负责人 | 建立cohort、安排教练、处理资源冲突和结业签署 |
| 产品经理教练 | 产品骨架、竞品边界、策略和证据表达 |
| 应用工程教练 | 工况、选型、排除条件、参数可比性和场景答辩 |
| 质量/法规教练 | 证书、材料、批次文件和合规范围 |
| 销售/供应链教练 | 客户决策、可比报价、产地、库存和实际交期 |
| 学员 | 按日提交产出，主动标记不确定项，不补造结论 |

教练不代替学员完成作业。复核的价值在于指出错误边界和补证路径。

## 5. 三次阶段检查

### DAY-10：产品与证据

- 建议总分门槛：60分。
- 必须能定位四家公司代表系列。
- 必须知道中国网页可见性不能证明库存、产地或交期。
- 出现致命错误时，即使分数达标也进入补课。

### DAY-20：应用判断

- 建议总分门槛：70分。
- 应用判断模块不得低于21分。
- 随机完成两个基础场景和一个高级场景。
- 必须先判断可比性，再推荐产品或竞争策略。

### DAY-30：结业

- 总分不低于75分。
- 产品骨架不低于14分。
- 参数与证据不低于14分。
- 应用判断不低于21分。
- 竞争策略不低于21分。
- 不得出现致命错误。

成绩录入 `training-scorecard.csv`。`total_score` 必须等于四模块之和。

## 6. 致命错误

出现以下任一情况，`fatal_error=YES`：

- 用产品族或集团能力代替具体型号能力。
- 把全球在售、中国网页可见或中国有工厂写成现货、本地产或短交期。
- 在没有同规格、同数量和同条款项目时断言价格优劣。
- 把承诺交期写成实际交期。
- 把网页图标、宣传语或CLAIM写成独立验证事实。
- 在关键工况缺失时给出确定选型。
- 隐去反证或为了结论凑入不合格样本。

致命错误不是惩罚标签，而是阻止错误竞争结论进入客户项目的质量门。

## 7. 补强与复测

未通过时，不重做全部30天。教练按最低模块安排5个工作日内的定向补强：

| 低分模块 | 补强动作 |
|---|---|
| 产品骨架 | 重做四家公司记忆地图和十个Bürkert产品角色 |
| 参数与证据 | 重做卫生阀归一化比较与证书审查 |
| 应用判断 | 重做两个失败场景并进行口头问诊 |
| 竞争策略 | 重做竞品攻防页和一条项目证据链 |
| 致命错误 | 针对错误规则完成反例练习并由教练复核 |

复测使用 `checkpoint=RETEST`，必须保留首次成绩，不能覆盖原记录。

## 8. 结业答辩

答辩建议60分钟：

1. 5分钟：四家公司定位和最大能力边界。
2. 10分钟：随机抽取一个Bürkert Type和一个竞品系列进行目录检索。
3. 20分钟：处理一个信息不完整的制药项目。
4. 10分钟：解释哪些信息不可比较以及为何。
5. 10分钟：提出技术、商业和证据三类下一步。
6. 5分钟：说明一个自己仍无法判断的问题。

答辩人如果能够明确说“无法判断，并说明要取得什么证据”，优于无依据地给出确定答案。

## 9. 结业后的60天

训练完成不等于市场事实成熟。每名学员在后续60天至少完成：

- 参与两个真实制药竞争项目。
- 填写两条完整项目日志。
- 贡献一条通过复核的内部证据。
- 更新一条战卡发现问题或排除条件。
- 在月度复盘中讲解一个输赢项目。

这些产出进入内部验证机制，而不是另建个人笔记体系。

## 10. 启动检查

首期开班前确认：

- 已指定项目负责人和至少一名产品/应用教练。
- 学员能访问研究目录，但敏感项目附件仍在受控文档库。
- 每名学员在进度表中预建30条记录。
- 已安排DAY-10、DAY-20和DAY-30评估时间。
- 已选择一个WFI项目和一个发酵供气项目作为跟随案例。
- 教练对致命错误和评分口径达成一致。

运行以下命令检查课程、成绩和过程记录结构：

```bash
python3 scripts/research/test_validate_product_training_program.py
python3 scripts/research/validate_product_training_program.py
```
