# 四家公司竞争产品知识库

研究范围：Bürkert、GEMÜ、Fujikin、ESG 精锐
重点市场：中国制药与生物技术
当前版本：2026-06-09

## 阅读顺序

1. `2026-06-four-company-competitive-research.md`
   用于理解整体市场判断、公司档案、十一维矩阵和行动建议。

2. `2026-06-product-manager-knowledge-playbook.md`
   用于掌握代表系列、制药应用、选型字段和知识边界。

3. `burkert-full-product-handbook.md`
   用于系统学习 Bürkert 十大产品族、全部当前 Type、选型变量和不可互换边界。

4. `2026-06-competitive-battlecards.md`
   用于客户拜访、方案评审和竞争报价前的快速准备。

5. `2026-06-product-knowledge-assessment.md`
   用于个人自测、团队培训和季度场景演练。

6. `2026-06-knowledge-maintenance.md`
   用于把新产品、报价、交期、输赢和售后事实持续回灌。

## 当前成熟度

**已经建立**

- 四家公司统一产品分类。
- 54条可追溯公开证据。
- 代表系列和六类制药应用地图。
- Bürkert全球官网当前Type全量目录、参数表和完整产品树。
- 三家竞品战卡。
- 100分产品知识自测。
- 竞争项目结构化记录与更新规则。

**仍需内部事实**

- 同规格真实净价与折扣。
- 标准品、定制品和备件实际交期。
- 中国具体型号产地与库存。
- 客户安装量、故障率、膜片寿命和审计体验。
- 可验证的输赢原因。

在这些内部事实补齐前，知识库可以支持产品和竞争讨论，但不能证明已经掌握中国市场中的实际商业优劣。
