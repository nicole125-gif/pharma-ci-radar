# 四家公司竞争产品知识库

研究范围：Bürkert、GEMÜ、Fujikin、ESG 精锐
重点市场：中国制药与生物技术
当前版本：2026-06-24

## 阅读顺序

1. `2026-06-four-company-competitive-research.md`
   用于理解整体市场判断、公司档案、十一维矩阵和行动建议。

2. `2026-06-product-manager-knowledge-playbook.md`
   用于掌握代表系列、制药应用、选型字段和知识边界。

3. `2026-06-product-knowledge-coverage-audit.md`
   用于判断当前知识成熟度、主要产品战场和下一阶段内部验证优先级。

4. `2026-06-pharma-application-field-guide.md`
   用于把客户任务转化为过程等级、候选产品、排除条件和下一步证据。

5. `2026-06-internal-validation-fieldbook.md`
   用于分派价格、交期、产地、证书、装机和服务验证任务，并控制结论升级。

6. `2026-06-product-knowledge-30-day-training-guide.md`
   用于组织30天产品熟练训练、阶段评估、补强和结业答辩。

7. `burkert-full-product-handbook.md`
   用于系统学习 Bürkert 十大产品族、全部当前 Type、选型变量和不可互换边界。

8. `gemu-pharma-series-handbook.md`
   用于查询 GEMÜ 当前官网系列、制药相关性、技术边界及与 Bürkert 的系列级映射。

9. `fujikin-product-series-handbook.md`
   用于区分 Fujikin 生命科学卫生、跨行业精密流控和半导体高纯三条能力线。

10. `esg-jingrui-product-handbook.md`
   用于查询 ESG 精锐可核验系列、证据等级、企业声明和内部验证缺口。

11. `2026-06-competitive-battlecards.md`
   用于客户拜访、方案评审和竞争报价前的快速准备。

12. `2026-06-product-knowledge-assessment.md`
   用于个人自测、团队培训和季度场景演练。

13. `2026-06-knowledge-maintenance.md`
   用于把新产品、报价、交期、输赢和售后事实持续回灌。

14. 四份 `2026-06-*-high-product-learning-cards.md`
   用于逐项学习四家公司全部136个制药高相关产品记录，覆盖公开规格、客户任务、选型必问、排除条件、竞品重叠、知识缺口和自测题。

## 网页演示路径

本地开发服务启动后，入口为 `http://127.0.0.1:3000/knowledge`。如果浏览器显示 localhost 拒绝连接，先确认 `npm run dev -- --hostname 127.0.0.1 --port 3000` 正在运行。

| 演示目标 | 页面路径 | 讲解重点 |
|---|---|---|
| 说明系统总览 | `/knowledge` | 展示511个 Bürkert Type、307条竞品系列记录、343条可引用证据、P0验证队列和只读/写入状态 |
| 从产品进入学习 | `/knowledge?view=products&q=8111` | 展示 Type 8111、C30/C33竞品映射、证据追溯和 `2026-06-24` 深度学习卡 |
| 验证 Fujikin 更新 | `/knowledge?view=products&q=PRETRONIC` | 说明 Fujikin PRETRONIC 只证明电动阀/执行器集成控制证据，不等同于独立卫生控制头组合 |
| 核查证据边界 | `/knowledge?view=evidence&risk=NEEDS_VALIDATION` | 区分 FACT、CLAIM、GAP 和 INTERNAL_VALIDATION，说明哪些结论不能直接升级 |
| 推进内部验证 | `/knowledge?view=validation` | 展示16项验证任务、P0队列、最小样本要求和价格/交期/证书/装机缺口 |
| 说明训练闭环 | `/knowledge?view=training` | 展示30天课程、阶段检查点、训练产出和待验证问题如何连接 |
| 输出管理层材料 | `/briefing` 和 `/briefing/markdown` | 展示管理层摘要、Top验证任务、行动分工和可导出的 Markdown 简报 |

演示时坚持三个边界：公开资料证明“产品存在和公开能力”，不证明中国现货、实际净价或真实交期；企业宣传保留 CLAIM 标记；威胁等级与证据可信度分开说明。

## 当前成熟度

**已经建立**

- 四家公司统一产品分类。
- 55条可追溯公开证据，其中 A/B 级48条。
- 14条 Bürkert 与 GEMÜ、Fujikin、ESG 精锐的系列级竞品映射。
- 12类制药应用场景地图。
- Bürkert全球官网当前Type全量目录、参数表和完整产品树。
- GEMÜ官网164个当前产品系列和精选解决方案记录、1547条规格记录及164条系列证据。
- Fujikin官方目录127条系列/型号族记录、467条目录规格、127条系列证据和10组Bürkert映射。
- ESG精锐16个可核验系列/系列组、58条参数或声明记录及9组Bürkert映射。
- 136张制药高相关产品深度学习卡：Bürkert 73、GEMÜ 50、Fujikin 9、ESG精锐4。
- 三家竞品战卡。
- 100分产品知识自测。
- Claude Code 项目记忆和三条项目命令：`review-knowledge`、`next-mainline`、`validate-research`。
- 竞争项目结构化记录、内部验证任务和知识更新规则。

**仍需内部事实**

- 同规格真实净价与折扣。
- 标准品、定制品和备件实际交期。
- 中国具体型号产地与库存。
- 客户安装量、故障率、膜片寿命和审计体验。
- 可验证的输赢原因。
- 第一批内部证据 intake 记录；当前 `2026-06-internal-evidence-intake.csv` 只有表头。
- 第一批训练进度记录；当前 `2026-06-product-knowledge-training-progress.csv` 只有表头。

在这些内部事实补齐前，知识库可以支持产品和竞争讨论，但不能证明已经掌握中国市场中的实际商业优劣。
